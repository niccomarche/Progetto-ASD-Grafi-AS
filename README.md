# Progetto-ASD-Grafi-AS
Implementazione in C++ di algoritmi su grafi (Dijkstra Minimax e DFS) per l'analisi di reti di Autonomous Systems (BGP).
## Come compilare ed eseguire il progetto
Per compilare il codice tramite terminale:
`g++ Progetto-ASD.cpp -o progetto_asd`

Per eseguire il programma, passa il file di testo contenente i dump BGP come argomento:
`./progetto_asd dataset_esempio.txt`
